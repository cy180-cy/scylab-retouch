# 净图

净图是一款在线图片工具。框选水印或小标记后，可以用周围的像素修补选区，也可以裁剪出需要保留的部分。图片在浏览器内处理，网站只提供页面和脚本。

[在线使用净图](https://retouch.scylab.top/)

## 怎么用

1. 点击「打开图片」，也可以把图片拖进页面或从剪贴板粘贴。点击「载入示例」可用内置样片体验。
2. 点击「选择区域」，框住要去掉的水印，再点击「确认去水印」。需要裁剪时，点「裁剪」，框出想保留的部分，再确认。
3. 点击预览区上方的「改名」，输入想用的文件名并保存，点「下载 PNG」即可导出。处理后可用「查看原图」对照。

支持 JPG、PNG、WebP 输入，统一导出 PNG。输入图片最多 1600 万像素，长边不超过 10,000 像素。修复适合背景简单、面积较小的选区。大面积遮挡或复杂纹理可能留下痕迹。

## 本地运行

项目使用 HTML、CSS、原生 JavaScript 和 Canvas。用浏览器打开 `dist/index.html` 即可使用。部署时把 `dist` 作为静态站点根目录即可。

| 文件 | 作用 |
| --- | --- |
| `dist/index.html` | 页面结构和图片工具入口 |
| `dist/style.css` | 页面布局、选区样式和工具图标的交互样式 |
| `dist/app.js` | 图片导入、框选、裁剪、原图对比和 PNG 导出 |
| `dist/repair.js` | 用选区边缘像素对遮挡区域进行多方向插值修复 |

修复时，页面把选区和周边的像素交给 Web Worker 处理，再把结果写回 Canvas。只有点击确认后才改变预览。导出使用 Canvas 生成 PNG。
